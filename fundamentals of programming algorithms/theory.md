# HTML: Введение

HTML - язык гипертекстовой разметки

HTML - язык гипертекстовой разметки (НурегText Markup Language). Описывает структуру и семантику (логику)
web-страницы. Всё то, что считывается браузерами. Браузеры движки обработки нашего кода (HTML+CSS+JS).
Приложения бывают двух видов: тонкий клиент (приложение мало весит, оно развернуто на сервере организации.
Мы клиенты подключаемся по протоколу НТТР/HTTPS (заходим на сайт) По сути, нам необходим лишь браузер)
и Толстый клиент (приложение много весит и устанавливается в оболочку ОС).
Примеры тонкого клиента: MS Teams (браузерная версия), Discord, Skype.
Примеры толстого клиента: СУБД 1С, Игры. Используются ресурсы вашего компьютера.

HTML-карскас страницы (вебприложения) в браузере. Состоит из тегоф (элементов) = блочные или строчные
элементы. Внутри элементов находится контент (текст, изображение, кнопки, списки, таблицы, формы)
Большинство тегов HTML - праные (тоесть име.т открывающий тег и закрывающий тег)

1. Блочный элемент - контейнер, имеющий парный тег и границы. Основыные правила:
Блочный элемент по умолчанию занимают всю ширину экрана пользователя.
Блочные элементы распологаются друг пож жругом если не влоэены а ижут в коде. высота блочного
Основные семантические теги:

1) Header - "Шапка сайта". Секция для вводной информации сайта или группы навигационных ссылок. Може содержать один или несколько заголовков, логотип, информацию об авторе.
2) Main - "Тело сайта". Контейнер для основного уникального содержимого документа. На одной странице должно быть не более одного элемента.

3) Footer - "Подвал сайта". Определяет завершающую область (нижний колонтитул) документа или раздела. Nav - Секция с навигацией (навбар).

4) Nav - Секция с навигацией (навбар).

5) Article - Раздел контента, который образует независимую часть документа или сайта, например, статья в журнале, запись в блоге, комментарий.
6) Section - Определяет логическую область (раздел) страницы, обычно с заголовком.
7) Aside - Представляет контент страницы, который имеет косвенное отношение к основному контенту страницы/сайта.
8) Div -  Элемент-контейнер для разделов HTML-документа. Используется для группировки блочных элементов с целью форматирования стилями.
Книга о тегах: https://html5book.ru/

## Формы
<form> - добавляет на страницу форму, которую пользователь может заполнить. Например, ввести своё имя, фамилию или почту. Данные формы отправляются на сервер.

       <form action="#">
            <div>
                <label>Логин</label>
                <input>
            </div>
            <div>Пароль
                <input>
            </div>
                <button>Войти</button>
                </form>
<label> - Добавляет текстовую метку для элемента <input>.
<input> - Создает многофункциональные поля формы, в которые пользователь может вводить данные.
<button> - Создает интерактивную кнопку. Элемент может содержать текст или изображение.

У элемента <input> имеется разнообразие типов:
text, email (проверка @), password, number, date (выбрать дату), checkbox(выбор варика в тестах), radio(выбор нескольких), file(позволяет вложить файл из проводника)

 <textarea name="" id="" rows="2"></textarea>
<select name="" id="">
    <option value="">Угловые диваны</option>
    <option value="">Прямые диваны</option>
</select>

<textarea> - Создает большое поле для ввода текста.

<select> - Элемент управления, позволяющий выбирать значения из предложенного множества. Варианты значений помещаются в <option>.

<option> - Определяет вариант/опцию для выбора в раскрывающемся списке <select>, <optgroup> или <datalist>.

## АТРИБУТЫ ЭЛЕМЕНТОВ HTML
src=".." - путь к изображению видео или скрипту
<img src="...">
<script src="./js.js">

href="..." - Адрес ссылки
<a href="...">

alt="..." - текстовое описание (исп для изображений)

title="..." - Дополнительная всплывающая подсказка

name="..." - Имя поля при отправке формы (атрибут для <input>)
<input type="text" name="...">

 value="..." - Значение поля
<input value="...">

type="..." - тип кнопок или поля ввода (применяется к <button> или к <input>)

placeholder="..." - Короткая подсказка внутри поля (input)

required - Обязательное поле
<input type="text" name="..." placeholder="Введите логин" required disabled>

disabled - Отключенный элемент

checked - Выбранный checkbox/radio (у элементов <input>)

class - Позволяет идентифицировать элемент CSS-классом (может повторяться у разных элементов)
<div class="firstClass">Первый блок</div>
<div class="secondClass">Второй блок</div>

id - Позволяет идентифицировать элемент (чаще используют для JS-скриптов). Должен быть уникальным и НЕ может повторяться у разных элементов.
<div id="firstId">Первый блок</div>
<div class="secondId">Второй блок</div>

<div class="firstClass" id="firstId">Первый блок</div> 




+ Можно добавлять кастомные атрибуты
